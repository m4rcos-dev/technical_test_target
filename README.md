# Teste Técnico Target

## Sobre
Este repositório contém as soluções do teste técnico para o processo seletivo da Target.

## Tecnologias Utilizadas
- JavaScript
- Node.js

## Configuração e Instalação
1. Clone o repositório

```bash
git clone git@github.com:m4rcos-dev/technical_test_target.git
```

## Como Executar
Cada solução pode ser executada individualmente usando Node.js:

```bash
node [nome-do-arquivo].js
```
